## 0–11 소스 인계

기존 Unity Editor를 종료/재시작하지 않고 Source/Prefab/FBX/Animator를 수정했다. `FPSKyle_Arms_0.asset`과 `PlayerAvatar.prefab`의 `FPS_KyleArmsSkinned`가 실제 생성되었다. CPU 읽기 가능한 Robot Kyle FBX 임포트 설정을 적용했다. `RemoteMotionAnimator`를 PlayerAvatar/NPCActor 두 프리팹에 연결하고 Host 조준 상태를 원격 WorldVisual에 전달하도록 보완했다.

중도 참가자에게 다음 라운드 시작 전 로컬 지면 관전 카메라를 제공하는 `LateJoinSpectatorRig`를 추가했다. 라운드에서는 현재 연결 참가자만 스폰과 초기 참가자 목록에 포함되도록 보정했고, 만장일치 Redo 시 접속자 1명 미만 상태에서 멈추지 않고 로비 복귀하도록 조정했다. NPC는 최초 생성 시 기존 NPC/플레이어 캡슐과 최소한의 중첩 검사를 한다. 중간 이동 강제 분산은 추가하지 않았다.

## QA 실제 수행 순서

1. **기본 인수**: Editor 컴파일 오류 0, 2개 씬만 활성, 정상 입력·닌네임·카메라·팔/총 시각 확인 (P10-001,003~005, C08-001~003).
2. **Relay 동시 접속**: Host/Client 2명 방 생성·실제 코드·Ping·NGO 단일 SceneManager 동기 이동·로비 복귀; 이후 8명까지 순차 접속·이탈 (C08-004~008, P10-002~003).
3. **스폰/이동/NPC**: 9개 고유 스폰과 NavMesh의 1층·옥상·경사로, 2명→16 NPC / 8명→64 NPC, NPC 전투 무반응 및 사망 뒤 같은 라운드 재생성 없음 (C05-001~007, P10-004~008).
4. **총기/Host 피격**: 조준 시작·완료·발사 후 재조준 래치, 0발 빈 클릭, Host Capsule/Raycast·지형 차폐·NPC 차폐·클라이언트 위조 시간 및 재전송 거절, 사망 후 입력 차단 (C03-001~021, P07-001~007).
5. **탄약**: RoundActive 시작 시 필드0, t=5/10/15초마다 1개, 상한 N, +5 최대10, 중복 충돌 1회 지급, 이전 라운드 세대 분리 (P10-009, C05-008~022).
6. **라운드/관전**: 5초 카운트다운, 1~2초 사망 3인칭→고스트 지면 이동/벽 통과 금지, 승자 앞쪽 카메라 및 5초 축하, 마지막 2인 유효 상호사망에서 최초 승인 사수만 득점 (C08-009~014, P07-008~011).
7. **Redo/late join/이탈**: 중도 입장 당 라운드 관전 및 다음 라운드 참여, 모든 접속자(사망/대기 포함) Redo 만장일치·이탈 시 분자/분모 갱신, 중복 점수/남은 NPC/픽업 없음 (C08-012, P10-010~012).
8. **매치 종료**: 선착3승 뒤 GameScene 내부 1/2/3위 Kyle 시상대, 2인 3위 공석, 이름·점수·최근 득점 동점순위, 시상대 종료 후 기존 방 로비에서 Host 재시작 (C08-016, P10-013).
9. **최종 UI·품질**: Part08 승인 와이어프레임 대조(파일 경로 재확인 필요), 16:9 외 해상도 및 긴 닉네임, 오디오 청취 검수, 8명 + 64 NPC + 반복 총격 성능·메모리·네트워크 지터 (C08-017, P07-007).
