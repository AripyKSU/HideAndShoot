# 1366×768 인게임 UI 개선안 — 승인 후 적용 완료

## 목적과 범위
전투 중 시야를 확보하고, 행동 판단에 필요한 정보만 표시한다. HUD, Tab 순위표, 관전/라운드 전환, ESC 메뉴, 시상식을 함께 점검한다. 2026-10-14 사용자 승인을 받아 적용했다. 조작법은 메인 화면의 접기 버튼과 인게임 H 안내로 제공한다. 최종 결과는 UI_COMPACT_IMPLEMENTATION_2026-10-14.md를 참조한다.

## 확인한 구조
- HUD 생성 코드에는 1920×1080 기준으로 설계한 620px 라운드 패널, 305px 생존 패널, 560×406px 순위표가 남아 있다. 기준 해상도만 1366×768로 낮추면 기존 패널의 비중이 커진다.
- 실제 Windows 빌드에서 HUD/ESC/시상식의 기준값은 1366×768로 확인했다. HUD의 라운드 패널은 500px로 줄여져 있지만 생존 패널과 간격이 약 2.5px뿐이다. 순위표는 560×406px로 화면 폭의 약 41%, 높이의 약 53%를 차지한다.
- 실제 저장된 배치에서 순위표와 관전 패널은 약 160×72px 겹치며, 순위표와 승자 알림은 약 315×124px 겹친다. 결과 상태에서 순위표가 자동 표시되므로 실제 동시 노출 문제가 발생한다. 카운트다운도 순위표와 가장자리가 겹친다.
- 참가 인원/최대 인원/3승 규칙, 방 코드, 조작법, HANDGUN // 01, 탄약 숫자와 10칸 막대가 반복 표시된다.
- 전투 외 모든 상태에서 순위표를 자동 표시하므로 카운트다운/라운드 결과와 함께 화면을 차지한다.
- 기존 UI QA는 주로 1920×1080 기준을 수동 축소해 렌더링한다. 실제 씬 CanvasScaler를 사용하는 상태 조합 검사가 필요하다.
- 메뉴 씬의 저장된 CanvasScaler는 현재 1377×768이며 PlayerSettings 기본 창 크기는 1024×768이다. 승인 후 실제 목표인 1366×768과 일치시키고, HUD/ESC/시상식도 함께 통일한다.

| 탄약 획득/감도 변경 | 작은 알림으로 잠깐 표시한다. 동일한 하단 알림 위치를 공유하여 동시 중첩을 막는다. 감도는 값이 바뀔 때만 표시한다. |

## 화면 상태와 우선순위
1. 전투: 상단 상태 줄 + 우하단 탄약 + 조준할 때 조준점. 기본 화면 중앙은 비운다.
2. 관전/중도 참가: 상단 상태 줄 + 관전/대기 상태. 전투용 하단 UI는 숨긴다.
3. Tab: 순위표를 표시하고 같은 공간의 일반 알림을 잠깐 숨긴다. 온라인 게임 시간은 멈추지 않는다.
4. 카운트다운: 숫자를 최우선으로 표시한다. 이 짧은 상태에서는 순위표를 자동으로 띄우지 않는다.
5. 라운드 결과: 승자와 승수만 간단히 표시한다. 전체 순위는 Tab으로 확인한다.
6. ESC/시상식: 해당 화면만 표시한다.

## 구현 방식
- 씬에 저장된 편집 가능한 UI를 기준으로 수정한다. 생성용 코드와 검증 도구도 같은 기준으로 맞춰 재생성 시 큰 패널이 돌아오지 않게 한다.
- 화면 가장자리 앵커와 중앙 예약 영역을 사용한다. 폰트는 본문 18~20px, 주요 숫자는 32~36px를 기준으로 검토한다.
- 긴 닉네임은 별도 열과 자동 글자 크기 조정으로 처리한다. 입력된 닉네임의 내용을 바꾸지 않는다.
- 화면 상태별 표시 규칙을 정리한 뒤 불필요해진 UI 참조를 안전하게 정리한다.

## 완료 기준
- 1366×768, 1280×720, 1920×1080에서 실제 CanvasScaler로 확인한다.
- 생존/관전/중도 참가/Tab/저탄약/획득 알림/감도 알림/카운트다운/승자/ESC/시상식 상태와 동시 발생 조합을 확인한다.
- 8명과 20자 한글·넓은 영문 닉네임에서 텍스트 잘림, 패널 겹침, 화면 밖 이탈이 없다.
- HUD는 조준점과 중심 시야를 가리지 않는다. 순위표는 키를 놓으면 즉시 닫히며 기존 조작과 온라인 라운드 진행을 유지한다.
- 에디터와 Windows 빌드 양쪽에서 최종 화면을 캡처한다.

## 승인 요청
이 권장안을 기준으로 UI를 구현해도 되는지 확인한다. 승인 전 UI 배치·표시 동작은 변경하지 않는다.
