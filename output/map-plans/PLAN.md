# 신규 맵 배치 계획 — 2026-10-16

기존 맵을 1번으로 유지하고, 2번 도시 순환도로와 3번 화성 전초기지를 추가하는 설계안이다. 두 신규 맵의 외곽은 각각 72×72m, X/Z 범위는 -36~36m다. 기존 InitialSceneBuilder와 CityNavMeshBaker의 72m 기준을 사용했다. Unity CLI에서 연결된 에디터를 찾지 못했으므로 현재 편집 중인 씬의 실측값은 아니다. 이번 작업은 계획 작성이며 기존 씬, 에셋, 코드, 게임 실행 상태를 변경하지 않았다.

좌표는 Unity (X,Y,Z), 북쪽은 +Z다. Y=0은 지상 바닥, 스폰 앵커 Y=0.2m는 현재 제작 코드의 발밑 여유를 따른다. yaw 0°=북, 90°=동, 180°=남, 270°=서다. 배치도 숫자는 스폰 후보 번호이며 고정 플레이어 번호가 아니다.

## 공통 플레이 기준

- 현재 SpawnPointRegistry는 정확히 9개 스폰 중 2~8개를 중복 없이 추첨한다. 새 맵에도 동일한 구조를 적용한다. 9번 스폰도 나머지와 동등한 후보다.
- 모든 스폰은 지상에 두며 고지에서 시작하는 이점을 주지 않는다. 스폰마다 두 방향 출구와 높은 엄폐를 마련한다. 전 스폰 쌍의 시작 시야 차단은 실제 블록아웃에서 확인해야 하는 목표다.
- 현재 PlayerLocalMotor에는 점프가 없다. 모든 높이 변화는 경사로로 연결한다. 보행 2.2m/s, 달리기 5m/s 코드 값을 설계 참고치로 사용했다.
- 주 이동로 유효 폭 4m 이상, 경사로 폭 4m, 보조 보행로 2.5m 이상을 목표로 한다. 중앙 건물 옆 도시 보행로는 대체로 5m다. 엄폐는 낮은 펜스만 사용하지 않고 높이 2.4~3.5m의 화물·설비·암석을 섞는다.
- 스폰 보호 포켓은 막힌 방이 아니라 양옆으로 빠지는 공간이다. 출구를 경사로 하나로 제한하지 않는다. 스폰 가까운 아이템은 시작 시 지급 아이템이 아니라 공용 랜덤 후보 지점이다.
- NPC는 지상과 접근 가능한 고지의 같은 이동망을 공유하도록 계획한다. NPC가 이동하지 않는 고지를 플레이어만 점유하는 상황을 피한다. 연결된 NavMesh, 층별 경로, 실제 NPC 도달 여부는 구현 후 검증한다.
- 아이템 후보는 맵당 16곳. 현재 탄약/탐지 아이템이 같은 후보 목록을 공유하고 점유 중복을 제외하므로 특정 ◇를 탐지 전용으로 예약하지 않는다. 앵커 Y는 해당 층 바닥 +0.22m로 두고 층을 정확히 지정한다. 현재 코드의 3m NavMesh 샘플링이 다른 층을 잡지 않는지 확인한다.

## 도시 순환도로

스케치의 핵심을 중앙 대형 건물 → 지상 순환도로 → 외곽 고지 도로의 구조로 해석했다. 도시 에셋은 큰 랜드마크 한 동과 작업장, 컨테이너, 도로 시설물에 집중한다.

| 구역 | 배치와 역할 |
|---|---|
| 중앙 건물 | 중심 (0,0), 바닥 20×20m, 높이 약 10m. 서로 반대편 시야를 차단한다. 산업 건물 모듈을 결합해 한 동의 외형으로 구성한다. 1차 계획에서 실내와 옥상은 비플레이 영역이다. |
| 지상 순환도로 | 중심선 X/Z=±19m, 기본 폭 8m, 도로 범위 ±15~23m. 코너·정류장·하역 화물로 시야를 분할한다. 주 교전/위장 동선이다. |
| 건물 옆 보행로 | 건물 외벽 ±10m부터 도로 안쪽 ±15m까지. 차도를 피해서 다음 면으로 이동하는 경로다. |

## 구현 단계와 완료 기준

1. 현 맵은 그대로 유지하고 새 두 맵을 별도 맵 루트/씬으로 만든다. 메뉴 선택→호스트의 맵 ID 확정→모든 클라이언트의 같은 씬 로드가 필요하다. 현재 한 GameScene 전제 코드와 도시 전용 NavMesh 베이커를 맵별로 대응시킨다.
2. 우선 72m 블록아웃, 지형 높이, 건물 바운딩, 경사로와 스폰 9곳을 작성한다. 점프 없이 모든 순환 경로가 이어지는지 정적으로 검사한다.
3. 에셋 배치, 시작 사선 차단, 스폰 출구 2개, 공용 아이템 후보 16곳을 작성한다. 고지 엄폐는 해당 고지의 바닥 높이에 놓는다. 경사로 입구와 착지면은 비운다.
4. 맵별 NavMesh 베이크와 모든 스폰·후보 지점·고지의 경로 검사를 끝낸다. 계단 외형은 연속 경사 충돌면을 써서 플레이어와 NPC가 같은 길을 이용하게 한다.
5. 마지막에만 Play 모드로 2인/8인 시작, 9개 후보의 무중복 추첨, 라운드 재배치, NPC 이동, 고지 아이템 바닥 위치, 스폰 사이 초기 시야, 고지 독점 여부를 확인한다. 이번 계획 단계에서는 Play 모드를 실행하지 않았다.

이 수치는 구현 가능한 초기 배치 기준이며 실제 콜라이더와 카메라 시야를 통한 공정성 검증이 끝난 수치는 아니다. 특히 도시 P4/P5와 화성 P4/P5 주변은 짧은 간격이므로 높은 가림물과 이동 분기의 효과를 우선 확인한다. 기준을 충족하지 못하면 주변 엄폐/스폰을 소폭 이동한다.
